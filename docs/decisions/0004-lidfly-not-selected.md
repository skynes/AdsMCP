# ADR-0004: LidFly не выбран для AdsMCP

- **Статус:** accepted
- **Дата:** 2026-10-08
- **Область:** provider MCP / быстрый запуск рекламы

## Контекст

LidFly был рассмотрен как быстрый hosted MCP-агрегатор для Яндекс Директа,
VK Ads и Avito. После авторизации пользователь должен подключать собственные
рекламные кабинеты в личном кабинете LidFly. MCP предоставляется как часть
сервиса по платной подписке около 900 ₽ в месяц.

## Решение

Не использовать LidFly как runtime-интеграцию AdsMCP и не добавлять его в
локальный provider allowlist.

## Причины

1. Это посредник для уже существующих кабинетов, а не рекламная платформа,
   которая позволяет создать и запустить собственную кампанию без внешнего
   сервиса.
2. Собственные кабинеты и авторизация должны подключаться через сайт LidFly.
3. Ежемесячная подписка не соответствует требованию быстрого запуска без
   постоянной платы посреднику.
4. Hosted backend добавляет внешнюю операционную и security-зависимость.

## Последствия

- LidFly можно оставлять в исследовательском каталоге только как benchmark.
- В рабочем контуре приоритет получают прямые рекламные платформы с собственным
  кабинетом и минимальной локальной credential-настройкой.
- Для Hong Kong/global-профиля первым кандидатом остаётся HilltopAds: у него
  есть собственный advertiser account, официальный MCP и campaign API; API key
  хранится локально и не требует подписки на агрегатор.
- Для СНГ self-hosted варианты Yandex/VK рассматриваются отдельно, потому что
  они требуют собственных provider-токенов, но не требуют подписки LidFly.
