# Discord-коннектор

AdsMCP подключается к Discord только через официальный bot API. Обычный Discord-
аккаунт, user token, пароль и self-bot не используются.

## Что поддерживает первая версия

- проверка bot token и текущей bot identity;
- список серверов, где установлен бот;
- список видимых каналов выбранного сервера;
- поиск участника по username/nickname внутри выбранного сервера;
- поиск по ограниченной последней странице сообщений одного канала;
- отправка одного текстового сообщения в выбранный канал после `confirm=true`.

Результаты поиска не сохраняются в SQLite и история канала не обходится целиком.
Наличие участника в сервере или найденное сообщение не означает согласия на
личный контакт или рекламу.

## Настройка

1. Создайте Application в [Discord Developer Portal](https://discord.com/developers/applications).
2. На странице приложения создайте Bot и скопируйте bot token в локальный `.env`:

   ```env
   DISCORD_BOT_TOKEN=...
   DISCORD_APPLICATION_ID=...
   ```

3. Сгенерируйте OAuth2 invite URL со scope `bot` и минимальными правами:
   `View Channels`, `Read Message History` и, только для согласованного канала,
   `Send Messages`.
4. Пригласите бота в сервер и проверьте через `ads_discord_status`.

Для поиска участников Discord использует endpoint Search Guild Members. Не
включайте privileged intents без необходимости и не превращайте поиск в выгрузку
полного списка участников.

## Правила записи

`ads_discord_channel_send`:

- требует `confirm=true` на каждый вызов;
- отправляет только одно сообщение длиной до 2000 символов;
- не отправляет личные сообщения участникам;
- не поддерживает массовую рассылку, циклы по участникам или обход прав канала;
- используется для согласованной публикации в канале/опроса в собственном
  community, а не для unsolicited advertising.

Discord Developer Policy запрещает контактировать с пользователями без явного
разрешения и таргетировать пользователей рекламой. Поэтому для лидов сначала
нужен явный сигнал/команда пользователя и human review, а публикация должна
соответствовать правилам конкретного сервера.
