# Community recommendations

This directory is the public contribution inbox for general, reusable AdsMCP
recommendations. Add or edit Markdown files here when a recommendation should
be shared with the project rather than kept as local account data.

The weekly contribution check may create a PR for recommendation-only changes
after the user has accepted the Free Use Rules and configured a GitHub fork.
Other project changes are also detected, but they require an explicit review and
`ads_github_contribution_create_pr` call with `confirm=true`.

Review every changed file for secrets, personal data, unsupported claims and
platform-specific obligations before accepting or merging a pull request.
