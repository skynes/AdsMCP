# Click.ru: текущий статус интеграции

Дата проверки: 2026-10-08.

## Что уже настроено

- API Token Click.ru проверен read-only запросом к `/V0/user`, авторизация успешна.
- Создан локальный профиль рекламодателя типа `PERSON`.
- В Click.ru создан физический плательщик; его идентификатор сохранён в рабочем контексте AdsMCP.
- Token и профили хранятся локально в `ADS_MCP_DATA/clickru-settings.json`; секреты не попадают в SQLite и документацию.

## Яндекс Директ: блокер

Создание Direct через API Click.ru сейчас остановлено на обязательной интеграции Яндекса:

1. `GET /V0/integrations` вернул успешный ответ, но список интеграций пуст.
2. Для `POST /V0/accounts` с `service: "DIRECT"` Click.ru требует `integrationId`.
3. По актуальной инструкции Click.ru интеграция появляется после ручной OAuth-авторизации в Яндексе через интерфейс Click.ru.

Поэтому без входа в Яндекс и выдачи OAuth-доступа Direct через этот API создать нельзя. Пароль Яндекса в AdsMCP сохранять не нужно.

Источники: [создание аккаунта Яндекс Директ](https://help.click.ru/97), [OpenAPI Click.ru](https://api.click.ru/V0/docs/).

## VK Реклама: блокер

Для VK используем `service: "VK_ADS"`; в схеме API `integrationId` для этого сервиса не обязателен. Кабинет создан успешно:

- название: `Филипенко — VK Реклама`;
- `accountId`: `123456`;
- статус: `ACTIVE`;
- контекст: пользовательский Click.ru аккаунт, не мастер-аккаунт.

Официальная инструкция Click.ru предупреждает, что для полноценного управления агентским VK-кабинетом может понадобиться новый мультиаккаунт VK с юридическим статусом «Физическое лицо» и выданным доступом: [VK Реклама через Click.ru](https://help.click.ru/4814).

Проверка через Click.ru VK MCP broker выполнена:

1. Broker handshake и вызов через локальный AdsMCP bridge проходят успешно.
2. Кабинет `123456` виден, но имеет `ready: false`, `vk_user_id: 0` и пустой `vk_login`.
3. `vk_ads_auth_check` возвращает, что кабинет создан в Click.ru, но ещё не заведён на стороне VK; отдельный VK-токен не выдаётся.
4. Автоматически создать требуемый VK-мультиаккаунт без ручного входа через VK ID брокер не может.

Поэтому VK Ads остановлен на ручной первичной привязке VK-мультиаккаунта. Кампании
и показы не создавались и не запускались.

## Итоговая точка остановки

В текущей схеме Click.ru оба направления требуют ручной внешней авторизации:

- **Яндекс Директ:** отсутствует OAuth-интеграция Яндекса (`integrationId` не получен).
- **VK Ads:** Click.ru-кабинет создан API, но отсутствует VK-мультиаккаунт и его доступ.

Возвращаться к этим направлениям нужно только после ручного шага в соответствующей
платформе либо при выборе другого агентского сервиса, который создаёт и держит
кабинет полностью на своей стороне.
