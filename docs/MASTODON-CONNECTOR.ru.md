# Mastodon-коннектор

AdsMCP подключает аккаунт к выбранному Mastodon/fediverse-инстансу через
OAuth 2 authorization-code flow с PKCE. Пароль, cookie и access token не нужно
передавать в чат.

## Подключение аккаунта

Предпочтительный способ — локальная панель AdsMCP:

1. Запустите панель через `ads_dashbord_start` и откройте возвращённый
   локальный URL.
2. В разделе «Интеграции → Mastodon / fediverse» укажите origin инстанса и
   локальное имя подключения, затем нажмите «Войти через Mastodon».
3. Подтвердите доступ на Mastodon. После этого инстанс вернёт код напрямую на
   локальный callback `http://127.0.0.1:<port>/api/mastodon/oauth/callback`;
   панель обменяет его на токен автоматически.
4. Статус появится в панели, а токен останется в локальном файле.

Запасной MCP-only способ (если браузер не использует локальную панель):

1. Вызовите `ads_mastodon_auth_start` с origin инстанса, например:

   ```json
   {"instance_url":"https://mastodon.social","account_id":"main"}
   ```

2. Откройте возвращённый `authorization_url` и подтвердите доступ.
3. Скопируйте одноразовый код, показанный инстансом, и вызовите
   `ads_mastodon_auth_complete` с этим кодом и возвращённым `state`.
4. Проверьте подключение через `ads_mastodon_account_list` или
   `ads_mastodon_status`.

В обычном сценарии authorization code не нужно передавать в чат: локальная
панель принимает его сама. MCP-only OOB-flow оставлен только как резервный путь.

По умолчанию запрашиваются только scopes для чтения аккаунта, статусов и
упоминаний, ответа на статус, подписки на выбранный аккаунт и изменения профиля. Свой список scopes можно
передать в `ads_mastodon_auth_start`, если конкретный сервер использует другую
политику разрешений.

Состояние подключений хранится в игнорируемом локальном файле
`ADS_MCP_DATA/mastodon-accounts.json`. Для альтернативной ручной настройки
одного аккаунта можно задать `MASTODON_INSTANCE_URL` и
`MASTODON_ACCESS_TOKEN` в `.env`; токен также никогда не возвращается MCP.

## Работа с упоминаниями

- `ads_mastodon_notification_list` читает ограниченную страницу только
  mention-уведомлений и возвращает контекст статуса;
- `ads_mastodon_hashtag_search` читает публичные hashtag timelines и возвращает
  кандидатов с ограниченными примерами постов, а также считает сигналы стоимости,
  лимитов, локальных моделей, MCP и проблем workflow; сам поиск никого не добавляет
  в подписки;
- `ads_mastodon_interest_search` запускает расширенный discovery-набор тегов
  (`Hermes`, `Qwen`, `OpenCode`, `localmodels`, `MCP`, `#лимиты`, `#локальныемодели`
  и смежные), поднимает посты с выраженной болью/намерением и сохраняет только
  ограниченные публичные excerpts и ссылки в `interest_contacts` и
  `interest_research_posts`; если такие посты попали в hashtag timeline, сюда
  попадут и федеративные публикации Friendica вроде поста с `#Hermes`;
- `ads_mastodon_follow` подписывает только один заранее выбранный аккаунт за
  вызов, требует `confirm=true`, OAuth scopes `read:follows` и `write:follows`;
  `read:follows` обязателен, чтобы перед подпиской проверить уже существующие
  отношения и не повторять follows;
- `ads_mastodon_reply` сначала загружает целевой статус, автоматически сохраняет
  mention автора и затем публикует один ответ на него; если автора нельзя
  определить, публикация прерывается;
- `ads_mastodon_public_mention` публикует один публичный пост с mention выбранного
  аккаунта или отвечает на выбранный публичный статус;
- `ads_mastodon_direct_message` отправляет один приватный Direct-статус выбранному
  аккаунту и автоматически добавляет его mention, чтобы Mastodon доставил сообщение;
- `ads_mastodon_message_batch` отправляет явно переданный упорядоченный список
  direct-сообщений, публичных mention или replies; для каждого элемента задаются
  получатель, режим и точный текст. Для режима `reply` mention автора исходного
  статуса добавляется автоматически;
- каждый ответ требует `confirm=true` и точный текст передаётся в том же MCP
  вызове;
- если видимость не указана, сохраняется видимость исходного статуса. Явно
  указать более широкую видимость нельзя.

## Изменение профиля

`ads_mastodon_profile_update` позволяет изменить display name, bio/note,
locked/discoverable/indexable, hide collections, язык и до четырёх полей
профиля. Неуказанные значения не меняются. Инструмент требует `confirm=true`.

Коннектор не выбирает получателей и тексты автоматически из результатов поиска,
но может отправить несколько явно переданных сообщений через
`ads_mastodon_message_batch`. Он не обходит moderation/rate limits: при rate limit
пакет останавливается без автоматических повторов и требует `confirm=true`.
Личный Direct-статус не является согласием получателя на дальнейший диалог; для
outreach сначала проверьте, что публичный пост действительно содержит запрос или
приглашение к контакту.
