## Сравнение OSS vs hosted (getmcpads class)

| | OSS self-host | getmcpads / Adspirer hosted |
|--|---------------|----------------------------|
| Setup | Dev token, OAuth, credentials per platform | Browser OAuth, one URL |
| Maintenance | You upgrade API versions | Vendor maintains |
| Safety | You implement confirm/audit | Built-in preview+confirm |
| Cost | Free (+ infra) | Free RO / $20-29 write |
| Fork/custom | ✅ Full control | ❌ |
| VK/Yandex/TG | ✅ Community exists | ❌/partial |

**Sweet spot:** fork `manlikemuneeb/ads-mcp` или `cesteral/mcp-open-advertising` + добавить Yandex/VK/Telegram adapters из community repos.

## Быстрые setup snippets

### Google official (read-only)
```json
{
  "mcpServers": {
    "google-ads-mcp": {
      "command": "pipx",
      "args": ["run", "--spec", "git+https://github.com/googleads/google-ads-mcp.git", "google-ads-mcp"],
      "env": {
        "GOOGLE_PROJECT_ID": "YOUR_PROJECT_ID",
        "GOOGLE_ADS_DEVELOPER_TOKEN": "YOUR_TOKEN"
      }
    }
  }
}
```

### Yandex Direct (askads npm)
```json
{
  "mcpServers": {
    "yandex-direct": {
      "command": "npx",
      "args": ["-y", "mcp-yandex-direct"],
      "env": { "YANDEX_DIRECT_TOKEN": "your_token" }
    }
  }
}
```

### Synter OSS (npm)
```bash
claude mcp add synter-ads --transport http https://mcp.syntermedia.ai
# or local:
claude mcp add synter -- npx -y @synterai/mcp-server
```

### Telegram Ads (Playwright)
```bash
pip install "git+https://github.com/Free-cat/telegram_ads_mcp.git"
playwright install chromium
telegram-ads-auth
```
