## OSS vs Hosted Comparison

| | OSS self-host | getmcpads / Adspirer hosted |
|--|---------------|----------------------------|
| Setup | Dev token, OAuth, credentials per platform | Browser OAuth, one URL |
| Maintenance | You upgrade API versions | Vendor maintains |
| Safety | You implement confirm/audit | Built-in preview+confirm |
| Cost | Free (+ infra) | Free RO / $20-29 write |
| Fork/custom | ✅ Full control | ❌ |
| VK/Yandex/TG | ✅ Community exists | ❌/partial |

**Sweet spot:** Fork `manlikemuneeb/ads-mcp` or `cesteral/mcp-open-advertising` + add Yandex/VK/Telegram adapters from community repos.
